# Benchmarks

One file per measurement run, e.g. `p2-inference.md` or `p4-voice.md`. Every file records:

- the date, the git commit, the hardware (CPU, RAM, GPU) and OS version
- the model, the quantization and the provider version
- the exact commands used
- the raw numbers (and the median and p95 where you repeated the run)

Never edit old results. Add a new file instead.
