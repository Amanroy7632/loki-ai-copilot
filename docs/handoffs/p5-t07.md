## Known limitations
- The tray uses the app icon; it isn't a monochrome macOS template icon.
- Mute is disabled until voice ships.
- A Quit whose cleanup takes longer than 2 s exits anyway; startup recovery marks unfinished tasks interrupted.
- The Settings model field is `required` for Ollama, so before onboarding the form can't be saved without typing a model (the runtime itself now allows it).

## Security implications
- New plugins, with no webview permissions: autostart is reached only through Loki's commands.
- Single-instance prevents two processes on one database.
- A dev build or overridden session can't register a login item.
- New license exception (ISC, Linux only), pending D-07.
